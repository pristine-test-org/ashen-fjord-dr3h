How the board works

Everything anyone adds to the shared list lands on one board, newest first, so you can see where things stand without opening a single item.

  • Add an item and it shows up for everyone.
  • Tick it off and it moves to the done pile.
  • The board shows the five most recent entries.

Items are kept for as long as the list exists.

Read the short version

Saffron keeps the board small on purpose: five rows, no filters, nothing to configure before you can see what is going on.
