Why a shared list helps

When everyone writes to the same list, nobody has to ask what is left to do. The answer is already there, and it is the same answer for everybody.

  • One place for every small task.
  • Nothing gets lost in a message thread.
  • Anyone can pick up where someone else stopped.

A calm list is a list people actually open.
